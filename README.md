# NH BOX — Android Movie & Web Series Streaming Platform

Production-ready Kotlin + Jetpack Compose (Material 3) Android Studio project featuring:
- **User App**: Design-locked Home Screen & Movie Details Screen, Search with filters, Watchlist, Offline Downloads (`DownloadManager`), Settings persisted in RTDB, and AndroidX Media3 ExoPlayer.
- **Admin Panel**: Role-based Red/Black dashboard with Movie/Series/Season/Episode CRUD, TMDB v3 import, compressed Base64 RTDB image pipeline (`ImageCompressionEngine`), Categories/Genres/Banners/Users/Notifications/Settings management.
- **Backend**: 100% Firebase Realtime Database + Firebase Authentication + `firebase/database.rules.json`.

See [SETUP_GUIDE.md](SETUP_GUIDE.md) for configuration and deployment steps.
